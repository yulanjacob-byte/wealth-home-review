首页整体框架

查看首页的整体布局、内容切换及进入二级页面后的返回表现。左侧采用已确认的新 UI 整合稿；没有新 UI 的部分继续沿用原交互原型。

页面结构与公共交互

  1. 顶部资产与账户服务：展示资产概览，支持金额隐藏、资产明细展开与收起；账户服务提醒位于资产区下方、宫格区上方，随展开区域下移。
  2. 常用服务与小宝服务区：宫格提供常用服务入口，“全部功能”进入服务目录；小宝内容区在宫格下方展示场景卡片。
  3. 三个内容 Tab：精选推荐、热点机会、自主选基。点击切换对应内容；“理财规划”本期不上线，不保留 Tab 占位。
  4. 底部导航与页面层级：底部导航与内容滚动区分开；二级页提供返回入口。安全区、固定入口的层级、遮挡与互斥由全局统一管理。
